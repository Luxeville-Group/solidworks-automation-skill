# Türkçe / English CAD terimleri

API adları ve SolidWorks komut adları kod içinde İngilizce kalır. Aşağıdaki karşılıklar ekip içi iletişim içindir; kurulu SolidWorks sürümünün menü çevirileri farklı olabilir.

| Türkçe | English | Açıklama |
|---|---|---|
| Parça | Part | Tek parça belgesi; `SLDPRT`. |
| Montaj | Assembly | Bileşenlerden oluşan belge; `SLDASM`. |
| Teknik resim | Drawing | Görünüş ve ölçüler; `SLDDRW`. |
| Eskiz | Sketch | Unsur oluşturmak için kullanılan 2D/3D geometri. |
| Unsur / özellik | Feature | Extrude, Cut, Fillet gibi modelleme işlemi. |
| Unsur ağacı | Feature Tree | Modelin işlem geçmişi. |
| Ekstrüzyon / doğrusal katı oluşturma | Extrude / Boss-Extrude | Eskizden doğrusal katı oluşturma. |
| Ekstrüzyonla kesme | Extruded Cut | Eskiz kesitini kullanarak malzeme çıkarma. |
| Döndürerek katı oluşturma | Revolve | Kesiti bir eksen etrafında döndürme. |
| Süpürme | Sweep | Bir kesiti yol boyunca taşıma. |
| Kesitler arası geçiş | Loft | Farklı kesitler arasında geçiş oluşturma. |
| Radyüs / yuvarlatma | Fillet | Kenar veya yüz geçişini yuvarlatma. |
| Pah | Chamfer | Kenarı mesafe/açı ile kırma. |
| Montaj ilişkisi | Mate | Bileşenler arasındaki geometrik kısıt. |
| Serbestlik derecesi | Degree of Freedom / DOF | İzin verilen bağımsız hareket. |
| Yeniden oluşturma | Rebuild | Modeli güncel parametrelerle yeniden hesaplama. |
| Konfigürasyon | Configuration | Aynı belgede ölçü/özellik varyantı. |
| Geçiş deliği | Clearance Hole | Cıvata veya vidanın diş açmadan geçmesi için boşluklu delik. |
| Kılavuz deliği / dişli delik | Tapped Hole / Threaded Hole | İç vida dişi olan delik. |
| Kılavuz ön deliği | Tap-drill Hole | Diş açılmadan önceki delik. |
| Vida dişi | Thread | Diş geometrisi veya diş gösterimi. |
| Kozmetik diş gösterimi | Cosmetic Thread | Gerçek helisel diş geometrisi oluşturmayan gösterim. |
| Silindirik havşa / fatura deliği | Counterbore | Silindirik baş yuvası. |
| Konik havşa | Countersink | Konik baş yuvası. |
| Kör delik | Blind Hole | Belirli derinlikte sonlanan delik. |
| Tam geçiş | Through All | Model kalınlığını geçen bitiş koşulu. |
| Uzun delik / kanal | Slot | Bağlama göre obround delik veya kanal. |
| Cep | Pocket | Malzeme çıkarılmış kapalı bölge. |
| Et kalınlığı | Wall Thickness | Duvarın yerel kalınlığı. |
| Referans | Datum | Ölçülendirme veya konumlandırma dayanağı. |
| Tolerans / geçme | Tolerance / Fit | İzin verilen sapma / eşleşen parçaların ilişkisi. |
| Çakışma / girişim kontrolü | Interference Check | Katıların ortak hacmini denetleme. |
| Malzeme listesi | Bill of Materials / BOM | Parça, adet ve özellik listesi. |
| Üretilebilirlik değerlendirmesi | Design for Manufacturing / DFM | Üretim yöntemiyle ilgili risk kontrolü. |
| Sonlu elemanlar analizi | Finite Element Analysis / FEA | Ağ, malzeme ve sınır koşullarıyla sayısal analiz. |
| Sınır gösterimi | Boundary Representation / B-Rep | Katının yüz, kenar ve köşe geometrisi ile bunların topolojik ilişkileri. |
| Ön kontrol | Preflight | Çalıştırma öncesi ortam/girdi denetimi. |
| İnceleme kanıtı | Review Evidence | Dosya, ölçüm, önizleme ve yeniden açma kayıtları. |
