# Routing for Gear Solids and Assembly Motion

## Identify the user's intent first

| User intent | Correct route | Prohibited substitution |
|---|---|---|
| Draw/model a gear part with real teeth | Use `scripts/sw_gear.py` for standard external spur gears; use specialized modeling for other gear types | Replacing a gear solid with a Gear Mate |
| Couple two gears, create draggable transmission, specify a mate ratio | `sw_assembly.add_gear_mate_by_cylinders()` | Presenting scripted fake animation as a Gear Mate |
| Production-grade industrial gear | Confirm gear system, profile shift, backlash, tolerances, modifications, material and strength; use specialist tools and engineering review | Claiming visualization geometry is production-ready |

When the user asks to draw a gear, do not automatically route to assembly mates merely because the skill is enabled. Manufacturing tasks require module, tooth count, pressure angle, face width and bore diameter. Defaults are permitted only for visual demonstrations and must be disclosed in the result.

## Current supported scope

`SpurGearSpec` covers only standard full-depth external involute cylindrical spur gears:

- Pitch diameter: `d = m * z`
- Base diameter: `db = d * cos(alpha)`
- Tip diameter: `da = d + 2m`
- Root diameter: `df = d - 2.5m`
- Circular tooth thickness: `s = pi * m / 2`

The tooth flanks sample the base-circle involute `inv(alpha) = tan(alpha) - alpha`. When the root circle lies below the base circle, the implementation uses radial transitions and root-circle arcs, not the true trochoidal root generated by a hob. It reports theoretical undercut risk but does not automatically design profile shifts.

## Minimal call

```python
from sw_gear import SpurGearSpec, create_external_spur_gear

spec = SpurGearSpec(
    module_mm=2.0,
    teeth=24,
    pressure_angle_deg=20.0,
    face_width_mm=10.0,
    bore_diameter_mm=10.0,
    involute_segments=14,
)
feature, evidence = create_external_spur_gear(model, spec)
```

`evidence` returns analytical dimensions, undercut risk, profile density and known limitations. Also read back the tip envelope and center bore from SolidWorks B-Rep using `collect_geometry_measurements()`, and verify saving, STEP export, four-view inspection and close/reopen behavior.

## Verified example

Real SolidWorks 2026 SP1.1 (Revision 34.1.1) example: `m=2`, `z=24`, `alpha=20°`, face width `10 mm`, bore `10 mm`. The result is one solid; B-Rep readback before and after reopening is `52 × 52 × 10 mm`, with a `10 mm` internal cylindrical face. SLDPRT and STEP were written successfully and four-view rule review returned `pass/100`. Production root geometry, backlash and tolerances are not covered, so the capability remains `pilot` and `review_required`.

## Scope that must not be claimed automatically

- Helical, herringbone, bevel or internal gears, racks, worm gears;
- Profile-shift coefficients, backlash, tip/lead modifications or exact hob-generated roots;
- ISO/GB/AGMA tolerance grades, material, heat treatment, contact/bending strength or NVH validation;
- Treating high sampling density as free: more chord segments slow SolidWorks modeling, STEP export and B-Rep traversal.
